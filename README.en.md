## Install

1. Download the APK — from the website or here, it's the same file.
2. Allow installs from your browser when Android asks.
3. Sign in with the [Telegram bot](https://t.me/LeroConnect_bot) or your subscription link.

Updates arrive inside the app.

## Verify the file

Each release lists its SHA-256 and a VirusTotal report.

<details>
<summary>How to check SHA-256</summary>

```bash

Get-FileHash lero-vpn-*.apk           # Windows (PowerShell)
```
